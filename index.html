Each variable is one question per article and one column in your data. Outlet, country, date, headline and pages are recorded for you, so leave them out.

Paste a codebook

One question per line as name | question | type | coding rule. Types are binary (Yes 1, No 0), single: 1=Market; 2=Governance, number or text. Pasting replaces the list above.

Reliability

With one coder, reliability comes from coding a random subsample twice. Wait about a week, recode the sample without seeing your first codes, and report Krippendorff's alpha for each variable. An alpha of .80 or higher is the usual benchmark, and .667 is the floor for tentative conclusions.

Outlets

One per line as Outlet name = Country. Chota looks for these names on each article's first page and in file names, and fills in the outlet and country for you. The order sets the numeric codes, so the first outlet is 1. Outlets you type in while coding are numbered after these.
